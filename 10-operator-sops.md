# 10 — OPERATOR SOPs

The standard operating procedures. The boring documents that determine whether you make money or burn out.

---

## 1. The weekly cadence (steady state)

Once the system is set up (~month 2), this is the schedule.

```
MONDAY (3 hrs)         Sourcing & inventory
TUESDAY (2 hrs)        Mythology + voiceover batch
WEDNESDAY (4 hrs)      Photo + macro shoot
THURSDAY (4 hrs)       Edit + schedule content
FRIDAY (1 hr)          Shopify estate update
SATURDAY (1 hr)        Comments / DMs
SUNDAY (1 hr)          Comments / DMs + weekly review
─────────────────────────────────────────
TOTAL                  ~15 hours/week
```

Months 0–2 will be 30+ hours/week building the library. That's the upfront cost.

---

## 2. Monday — sourcing & inventory

**Goal:** keep the next 14 days of inventory locked.

```
[ ] Open 1688 / Yupoo
[ ] Review existing supplier list — any new arrivals from current vendors?
[ ] Search for 2–3 new candidate hero pieces (use search terms in file 03)
[ ] Cross-reference any candidate on Yupoo for QC photos
[ ] If shortlist of 5 reached, order samples ($50–80)
[ ] Place reorder for any SKU with <5 units left
[ ] Update Airtable inventory tab:
      Current count, incoming order qty, ETA, unit cost
[ ] Confirm next week's photo shoot SKUs
[ ] Pay any outstanding invoices to sourcing agent
```

### Sourcing agent communication template

When working with a sourcing agent (Yansourcing, BasetaoSourcing, etc.):

```
Hi [Agent],

New inquiry. Please source the following:

ITEM:        skeleton mechanical watch, off-white dial, 38mm, no logo
LINK:        [1688 URL]
QUANTITY:    10 units initial, 50 if quality confirmed
NOTES:       
- No visible logos on dial, caseback, or strap
- Strap should be brown leather, aged appearance preferred
- Need photo of caseback before payment
- Need video of running movement before payment

QC CHECK:
- 5/5 units must wind smoothly
- 5/5 units must run >24 hours after winding
- 5/5 units must have aligned indices

Please confirm pricing and timeline.

Thank you.
```

## 3. Tuesday — mythology + voiceover

**Goal:** generate 14 days of content text in 2 hours.

```
[ ] Open Claude / GPT-4 with brand bible system prompt
[ ] Generate 30 mythologies for upcoming SKUs (use file 06 prompt)
[ ] Edit each for voice (forbidden words, sentence length, tense)
[ ] Save to Notion mythology database, tagged by SKU
[ ] Open ElevenLabs
[ ] Generate voiceover for each mythology (the lead sentence + lore beat)
[ ] Save .wav files named: VO_LOT[number]_[type].wav
[ ] Post-process: add tape hiss, vinyl crackle layer
[ ] Backup voiceovers to Drive / Notion
```

**ElevenLabs efficiency tip:** generate 30 mythologies as a single text block separated by `[break]` markers. Costs same credits, saves 80% of clicks.

## 4. Wednesday — photo & macro shoot

**Goal:** 80+ raw clips and 30+ stills in 4 hours.

### Pre-shoot setup (15 min)

```
[ ] Window light position confirmed (afternoon, ~2pm ideal)
[ ] Surface laid: cracked concrete, then linen, then walnut
[ ] Macro lens attached
[ ] Phone fully charged + storage cleared
[ ] LUT preview app loaded for color check
[ ] All watches fully wound, ticking
[ ] Evidence elements ready: tags, paper, polaroids
```

### Per-watch capture (15 min each, ~5 watches)

```
[ ] 5x dial macros (different details, varied angles)
[ ] 3x crown action (winding, click)
[ ] 2x rotor spin (skeleton backs)
[ ] 3x lug profile (light catching)
[ ] 2x strap close-ups (stitching)
[ ] 2x clasp action
[ ] 3x watch placed on different surfaces (linen, concrete, walnut)
[ ] 1x caseback (with fictional engraving if applicable)
[ ] 5x stills for product page (square format)
[ ] 1x watch with evidence element (tag, paper)
```

Total: ~25 clips and 5 stills per watch × 5 watches = 125 clips, 25 stills.

### Post-shoot (30 min)

```
[ ] Review footage on big screen
[ ] Reject any out-of-focus or shaky clips
[ ] Apply LUT to a sample clip — confirm look
[ ] Tag clips in Airtable footage library
[ ] Backup raw footage to external drive
```

## 5. Thursday — edit & schedule

**Goal:** 14 reels + 4 ambient + 5 notes posts edited and scheduled.

### Editing template (DaVinci Resolve / CapCut Pro)

Build a reusable project template with:
- LUT applied to all clips
- Voiceover track pre-loaded
- Sound design library accessible via shortcuts
- Text-on-screen template (monospace, lower-third, white-on-black bar)
- Aspect ratio locked at 9:16 (1080×1920)
- Output preset: 1080×1920 H.264, ~12 Mbps

### Per-reel workflow (15 min each)

```
[ ] Open project template
[ ] Drop in 2–3 macro clips for hook
[ ] Drop in voiceover line (chosen for this lot)
[ ] Add tactile sound on action moment
[ ] Add ambient bed at -22dB
[ ] Add text overlay: LOT [number] / [city] / [year]
[ ] Add closing text: lot number + "available now"
[ ] Review at full speed — does the rhythm work?
[ ] Export at 1080×1920
[ ] Drop in scheduling tool with caption
```

14 reels × 15 min = 3.5 hours.

### Scheduling tool setup

Use Metricool or Later for multi-account scheduling.

```
[ ] Schedule 14 main account posts across 7 days, 2 per day
[ ] Schedule 4 field account posts on Tue/Thu/Sat/Sun
[ ] Schedule 5 notes posts on Mon/Wed/Fri/Sat/Sun
[ ] Confirm caption format consistency
[ ] Verify hashtags (2–4 max per post)
```

## 7. Saturday/Sunday — comments & DMs

**Goal:** in-character engagement only. ~1 hour per day.

### Comment management protocol

```
[ ] Sort comments by recent across all 3 accounts
[ ] Reply to genuine product questions in voice (see templates below)
[ ] Reply to "where are you based" / "is this real" with archival deflection
[ ] Like (don't reply to) comments that are positive but don't ask anything
[ ] Ignore or single-line dismiss negative trolls
[ ] Delete comments that contain spam links or phone numbers
[ ] Screenshot any comment worth turning into UGC content
```

### Standard reply templates (copy-paste ready)

**"How can I get one?"**
> *LOT [number]. Available now.*

**"How much?"**
> *[price]. Lot record contains specifications.*

**"Is this a real Rolex/AP/etc?"**
> *No. The archive holds unbranded objects only.*

**"Where do you source these?"**
> *Estates, brokerages, private handlers. Origins are documented per lot.*

**"Where are you based?"**
> *The handling facility is in transit.*

**"Is this real vintage?"**
> *Provenance is partial. Specifications are stated on each lot's record.*

**"Are these handmade?"**
> *We do not make objects. We select them.*

**"Can you make a custom one?"**
> *Custom acquisitions are not currently accepted.*

**"Is this dropshipping?"**
> *No reply.* (Or: *The archive holds inventory directly.*)

**"What movement does it have?"**
> *Mechanical automatic. Specifications are listed on the lot record.*

### DM protocol

```
[ ] Check DMs across all 3 accounts daily
[ ] Reply only in voice
[ ] Never reply with "Hi!" or "Hey there!"
[ ] Order inquiries: redirect to store with lot number
[ ] Press / collab inquiries: redirect to correspondence@[brand].com
[ ] Refund / shipping: redirect to correspondence@[brand].com
[ ] If someone DMs the field/notes account, reply with: "Inquiries are handled at correspondence@[brand].com"
```

## 8. Customer service voice guide

CS is the highest-leverage brand surface. One bad reply destroys the world.

### Reply principles

- Always in voice
- Past tense, passive voice
- Solve the problem, then close
- No apologies that read as marketing ("So sorry for any inconvenience caused!")
- One brief acknowledgment is acceptable: "We regret the delay. The dispatch is being expedited."
- Sign every email *— Section B*

### Common scenarios

**Order status inquiry:**

```
Subject: Re: order status

The dispatch left the handling facility on {{ ship_date }}.

Tracking is below.
{{ tracking }}

Estimated arrival is {{ estimated_arrival }}.

— Section B
```

**Damaged item:**

```
Subject: Re: damaged object

The damage has been logged.

A replacement will be dispatched within 48 hours. Photographs of 
the damage are not required for this acquisition. The damaged 
object may be retained or returned at your discretion.

A separate dispatch notice will follow.

— Section B
```

**Refund request:**

```
Subject: Re: return

The return has been logged.

Please dispatch the object to:

[archive return address]

The refund will be processed within 5 business days of receipt.

— Section B
```

**Wrong item received:**

```
Subject: Re: incorrect dispatch

The error has been logged.

The correct object — LOT {{ correct_lot }} — will be dispatched
within 48 hours. The incorrect object may be retained or returned
at your discretion. A return label is attached if return is preferred.

— Section B
```

**General compliment / fan email:**

```
Subject: Re: [their subject]

Received with thanks.

— Section B
```

That's it. No "We're so glad you love your watch!" The restraint is the brand.

## 9. The VA training (when you hire)

When daily order volume exceeds 30, hire a VA for fulfillment + comment management.

### Required materials for VA onboarding

1. The brand bible (file 01)
2. The customer service voice guide (this file, section 8)
3. The packing SOP (file 08, section 5)
4. The reply template library (this file, section 7)
5. A 5-page "voice study" with 20 examples of correct vs incorrect replies
6. Access to Shopify (limited to fulfillment role) and inbox

### The VA test

Before going live, give the VA 10 mock customer scenarios. Score their replies.

- 9/10 in voice: hire
- 7-8/10 in voice: train more, retest
- <7/10: do not hire. Voice failure costs more than VA cost saves.

### VA performance review (weekly first month)

```
[ ] Read 20 random VA replies from past week
[ ] Tag any voice violations (forbidden words, exclamations, etc.)
[ ] Calibrate with examples
[ ] Re-test if needed
```

## 10. The weekly review (Sunday, 30 min)

Every Sunday, do this. Don't skip.

```
[ ] TikTok metrics
    Top 3 posts this week — what was the hook?
    Bottom 3 posts — why did they fail?
    Total profile views, profile→link clicks
    Net follower growth across 3 accounts

[ ] Shopify metrics
    Orders this week
    Conversion rate (sessions → orders)
    Average order value
    Top 3 SKUs by units sold
    Bottom 3 SKUs (consider archiving if <2 units in 30 days)

[ ] Klaviyo metrics
    New subscribers this week
    Welcome flow conversion %
    Open rate on most recent send
    Reply rate (Ledger candidates)

[ ] Inventory
    SKUs below 5 units (reorder Monday)
    SKUs sold out (archive on store, mention in next field correspondence)
    Inventory aging (any SKU >30 days no sales = consider deprecation)

[ ] Customer service
    Tickets opened vs closed
    Refund rate (target <2%)
    Any patterns? (one supplier with quality issues?)

[ ] One thing to double down on
    What worked this week?

[ ] One thing to cut
    What didn't work? Stop doing it.
```

## 12. The discipline rule

The system runs on consistency, not creativity. After month 2, your job is **execution**, not invention.

The temptations that destroy operations:

- "Let me try a different voice this week to see if it works better."
- "Black Friday is coming, just one small sale won't hurt."
- "This trending sound is perfect, let me hop on it."
- "I'll show my face just this once for credibility."
- "Let me add a popup, just to capture emails better."

Each of these is a 1% short-term lift and a 30% long-term loss. **Hold the line.**

The brand bible is the source of truth. When in doubt, re-read file 01.
