# LEGACY — Reference Archive

This folder contains the original operator kit written for earlier brand iterations:

```
Mörk → Kairo → TISIDIAN
```

The brand evolved through three names and two major positioning shifts:

| Stage | Concept | Status |
|---|---|---|
| **Mörk** | Faceless archive, fictional estates, "recovered objects" | Replaced |
| **Kairo** | Same archive concept, dark vault aesthetic | Replaced |
| **TISIDIAN** | Modern luxury brand, accessible pricing, AI-generated cinematic content | **Current** |

---

## What's in here

14 files originally numbered 00-13, written for the archive concept:

- `00-sprint-launch.md` — 30-day sprint to first $5K
- `01-brand-bible.md` — Voice rules, forbidden words, naming
- `02-visual-system.md` — Colors, fonts, photography grammar, LUT spec
- `03-product-and-pricing.md` — Sourcing, pricing tiers, sample protocol
- `04-shopify-build.md` — Theme spec with Liquid + CSS code
- `05-tiktok-content-system.md` — Dossier reels, 3-account network
- `06-ai-workflow.md` — Claude prompts, ElevenLabs voice, batching
- `07-mythology-bank.md` — 50 archive mythology templates
- `08-packaging-system.md` — Unboxing components, vendor list
- `09-email-flows.md` — Klaviyo flows with copy
- `10-operator-sops.md` — Weekly cadence, customer service voice
- `11-zero-to-5k-roadmap.md` — Slower 8-10 week bootstrap
- `12-twelve-month-roadmap.md` — Scaling to $500K/month
- `13-failure-modes.md` — 15 ways this dies and how to prevent each

## What still applies to TISIDIAN

Even though the brand pivoted away from the archive concept, several pieces of the legacy kit remain useful:

### Still useful
- ✅ Faceless operation principles
- ✅ Discount policy (never)
- ✅ No popups / no "X people viewing" / no urgency widgets
- ✅ Page speed targets, mobile-first design
- ✅ Multi-account TikTok structure (3 accounts)
- ✅ Failure modes (`13-failure-modes.md`) — still 100% applicable
- ✅ Email flow STRUCTURE (welcome / post-purchase / win-back)
- ✅ Packaging philosophy (UGC engineering)
- ✅ Customer service voice principles (calm, clean, no exclamation)

### Replaced or obsolete
- ❌ "Section K / Section B" handler signature
- ❌ Lot numbers (049-A format)
- ❌ Estate/archive mythology
- ❌ "Recovered from..." product copy
- ❌ "Selected, not designed" tagline
- ❌ Cream parchment dossier cards
- ❌ The world-building voice (replaced with modern luxury voice)
- ❌ Posting cadence of 14 main posts/week (TISIDIAN runs 3 posts/day on main)

---

## Why we keep this

Three reasons:

1. **Reference for principles** — the 13 failure modes file alone is worth keeping
2. **Audit trail** — shows the evolution of thinking, useful when re-evaluating decisions
3. **Re-use** — if a future side project needs an archive-style brand, the kit is already written
