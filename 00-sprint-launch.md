# 00 — THE SPRINT (30 DAYS TO FIRST $5K)

The compressed path. First sale by day 14. First $1K by day 21. First $5K by day 42.

This is the version optimized for **speed to first dollar**. It sacrifices some upfront polish for momentum. You can build the polish back in starting month 2.

If you want the longer, safer version, read [11-zero-to-5k-roadmap.md](./11-zero-to-5k-roadmap.md). If you want speed, follow this.

---

## What makes this faster

The original 8–10 week path is conservative. The sprint compresses it via 6 specific levers:

1. **Pre-warm the accounts during build week.** Post field/notes content from day 1 even without products. Trains the algorithm + builds 200–800 followers ready to convert when products go live.
2. **DHL Express samples.** $80 instead of $30. Saves 5–7 days. Worth every cent.
3. **3-SKU MVP.** Launch with 3 watches, not 8. Less to inspect, less to photograph, faster to ship.
4. **Pre-orders during transit.** "Estate received, cataloging in progress" — accept deposits on items before they're in your hands. Aligns with the world's voice.
5. **Daily check-ins, not weekly.** Sprint mode = daily 10-minute review. Course-correct in hours, not weeks.
6. **All decisions pre-made.** Name, voice, color, fonts — locked. No deliberation. Execute.

## Day 1 — Lock the namespace (2 hours)

The name is **Mörk** (committed in [01-brand-bible.md](./01-brand-bible.md)). The verification protocol:

```
[ ] Check mörk.com (Namecheap, Google Domains)
    If taken, fall back in this order:
       mork.archive
       morkarchive.com
       morkco.com
       mork.studio

[ ] TikTok handles (in order of priority):
       @mork              ← if available, gold
       @mork.archive      ← excellent fallback
       @morkarchive       ← acceptable
    Plus the same patterns for:
       @mork.field
       @mork.notes

[ ] Instagram handle: same priority
[ ] X / Twitter handle: same (low priority but lock it)
[ ] Klaviyo account: register under "Mörk"
[ ] Shopify trial: register store with chosen domain
[ ] Email forwarding setup:
       correspondence@[domain]  → your inbox
```

If `@mork` is taken on TikTok, **do not** add numbers (`@mork99`). Step down to `@mork.archive` instead. Numbered handles look amateur.

If both `mork` AND `mork.archive` variants are unavailable, fall back to second name: **Vellum** → **Korr** (in that order). All other decisions in this kit stay the same.

**Time-box this:** 2 hours max. If you can't lock the namespace by lunch on day 1, you're over-thinking. Pick first available variant and move on.

## Daily 10-minute check-in (every day, sprint mode)

This replaces the weekly review for the first 30 days.

```
[ ] How many orders since yesterday?
[ ] Top post by views in last 24h — what was the hook?
[ ] Bottom post — was the hook slow? Lighting off? Voice off?
[ ] Inventory check: any SKU below 3 units?
[ ] Klaviyo: any new subscribers? Any replies to "correspondence open"?
[ ] DMs: in-character replies to any genuine product questions
[ ] Comments: same
```

Five minutes of metrics, five minutes of in-character engagement. Daily.

## What the sprint sacrifices (be honest)

To gain speed, the sprint gives up some things:

1. **Less footage variety** in week 1 — you have 3 SKUs not 8, so videos repeat sooner
2. **Less safety buffer** — if 2 of 3 samples are defective, you have a 3-day delay
3. **Less polished homepage** — the dimmed B&W hero photo will be a stock image, not a custom shoot
4. **Less time to refine voice** — you commit to one ElevenLabs voice on day 4, not after a week of testing

All of these are recoverable. After day 30, you switch to the steady-state cadence (file 10) and refine.

---

## When NOT to use the sprint

The sprint assumes:
- ~$300 starting capital available immediately
- 30+ hours/week available for the first 14 days
- Decisive personality (won't deliberate over name choice)
- No major life events in the next 6 weeks

If any of these aren't true, use the slower path in [11-zero-to-5k-roadmap.md](./11-zero-to-5k-roadmap.md) instead.

---

## The single rule that makes the sprint work

> **Don't pivot in the first 21 days.**

The sprint is engineered. The cadence, the timing, the milestones — all interlocked. If you change one variable in week 1 ("let me try a different voice," "let me skip the field account this week"), the whole thing slips.

Trust the system for 21 days. Reassess at day 22 if anything's off. Not before.

The discipline is the speed.
